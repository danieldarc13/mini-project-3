# Arrays & Objects

A hands-on JavaScript data lab using U.S. National Park data to practice core array and object concepts.

## Built With

- JavaScript

## Sections

- **Part 1 – Arrays**: Creating and iterating over an array of park names using `for`, `for...of`, `forEach`, `map()`, `filter()`, and `find()`
- **Part 2 – Objects**: Building and manipulating individual park objects using dot and bracket notation, nested objects, methods, and `this`
- **Part 3 – Arrays of Objects**: Working with a full parks dataset using `forEach`, `filter()`, and `map()`
- **Part 4 – Object Manipulation**: Copying objects with `Object.assign()`, reference vs. value behavior, and `const` with objects and arrays
